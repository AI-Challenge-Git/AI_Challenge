# MTS SOS Desk

MTS SOS Desk는 고객이 자유롭게 작성한 MTS 오류 제보를 AI로 분석하여 장애 의심 신호와
개별 상담 맥락을 제공하는 증권사 도입형 웹서비스 MVP입니다.

## 해결하려는 문제

장애 초기에는 같은 증상을 겪은 고객들이 서로 다른 표현으로 문의합니다. 기존 문의 목록만으로는
제보 사이의 관계를 빠르게 파악하기 어렵고, 상담원도 전체 장애 맥락 없이 같은 확인을 반복하게 됩니다.

MTS SOS Desk는 다음 흐름으로 이 문제를 해결합니다.

1. 고객 제보에서 기술적 장애 증상과 개인 주문 상담정보를 분리합니다.
2. 개인정보를 제거한 기술 증상만 의미 기반으로 군집화합니다.
3. 일정 시간 동안 유사 제보가 증가하면 장애 의심 신호를 생성합니다.
4. 운영자에게 신호의 공통 증상과 근거를 제공합니다.
5. 상담원에게 현재 고객의 상담카드와 비식별 장애 맥락을 함께 제공합니다.

## MVP 범위

- KB증권 M-able 국내주식 매도 장애 의심 시나리오
- 고객·상담원·운영자 Mock 사용자 흐름
- 텍스트 제보 구조화, 개인정보 마스킹, 의미 기반 군집화
- 장애 의심 신호 상황판과 상담 준비카드
- 고객 입력값과 상담원 확인값의 누락·불일치 탐지
- 원문·키워드·AI 방식 비교 평가

AI는 장애를 공식 확정하거나 주문을 실행하지 않습니다. 실제 계좌, 본인인증, 주문, 보상 시스템과도
연결하지 않습니다.

## 기술 구성

- Backend: Python 3.13, FastAPI, Pydantic v2
- Database: PostgreSQL 16, pgvector, SQLAlchemy 2.x async, Alembic
- Frontend: React, Vite, TypeScript
- Infrastructure: Docker Compose
